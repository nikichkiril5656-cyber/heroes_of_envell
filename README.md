# Герои Энвелла (Fabric, Minecraft 1.21.1)

## Сборка
Нужны JDK 21 и Gradle.
    gradle wrapper --gradle-version 8.8
    ./gradlew build        # jar в build/libs/
    ./gradlew runClient    # тестовый запуск

## Как играть
1. Обычная игра. Ноутбук-портал лежит в сундуках структур (любой ванильный сундук, шанс 5%).
   В креативе он есть во вкладке «Герои Энвелла».
2. ПКМ с ноутбуком: переход в измерение Энвелл (запоминается точка возврата).
3. При первом входе открывается меню выбора класса. **Выбор окончательный** (нужно подтверждение вторым кликом), сменить класс нельзя. Клавиша R: способность. Если закрыли меню, откройте его снова: `/envell class`.
4. ПКМ с ноутбуком внутри Энвелла: возврат. Shift+ПКМ внутри: вызвать Моргарта.
5. Вне Энвелла классовые бонусы, HUD и способности отключены. Опыт копится отдельно по каждому классу.

## Классы (по вики «Герои Энвелла»)
| Класс | Роль | Бонусы за уровень | Способность (R) |
|---|---|---|---|
| Рыцарь | ближний бой | здоровье, урон, броня | рывок со щитом, урон монстрам рядом |
| Маг | магия | здоровье, урон, удача | огненная волна по конусу |
| Вор | дальний бой, скрытность | скорость, урон | невидимость (союзника рядом тоже) |
| Инженер | поддержка | броня, скорость атаки | турель (до 2 шт.) и ремонт предмета |
| Бард | поддержка | здоровье, скорость атаки | гипноз врагов, усиление и подзарядка союзников |

Команды: `/envell class` (открыть выбор, пока класс не выбран), `/envell stats`.
Для админов (тестирование): `/envell resetclass` сбрасывает выбор.

## Мир Энвелла
Островной мир: в клетках 112x112 блоков висят острова (трава, земля, камень с рудами, деревья, цветы), под ними пустота.
Соседние острова соединены мостами с перилами и фонарями. Остров (0,0) и его соседи есть всегда. Игрок появляется на острове (0,0).
Параметры (расстояние между островами, размеры) находятся в начале `IslandGenerator.java`.

## Мобы островов
Моб появляется на острове один раз при его создании (главный остров без мобов). Новых мобов добавляйте в `IslandMobs.populate`.

### Шкатулка жадности (мини-босс, 3 стадии)
- Стадия 1: шкатулка, не нападает. ПКМ даёт золотую монету.
- Больше 20 монет: просыпается (мини-монстр, нападает; монеты брать всё ещё можно).
- 100 монет: превращается в большого монстра, монеты больше не даёт.
- Слабые места: золотые инструменты и оружие (урон x2), кислота и магия (x2.5). Колба с кислотой: стекляная бутылка + паучий глаз + слизь, ПКМ по существу.
- Стадия 2 и 3: удар крадёт монеты из инвентаря игрока (2 и 6 штук), босс лечится. Украденное выпадет после его смерти.
- Стадия 3: полоса здоровья, удар по земле раз в 8 секунд (10 урона и отбрасывание в радиусе 5 блоков).
- Лут: монеты (стадия 2 и 3 дают ещё золотые слитки).
